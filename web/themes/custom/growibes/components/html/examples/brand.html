02 / The common visual system

Different chapters.
Same DNA.

01 / TYPE

Big type.

Display typography does the positioning work. Short headlines. Tight tracking. One dominant idea per viewport.

02 / SPACE

Editorial pace.

Fewer sections, more breathing room. Complex engineering gets room to be understood.

03 / MATERIAL

Glass, not gloss.

Frosted surfaces become a material language for systems, controls and evidence — never decoration for its own sake.

04 / SIGNAL

Blue means action.

Electric blue is the persistent Growibes signal. Lime is reserved for proof, opportunity and high-value moments.

05 / MOTION

Motion explains.

Orbital lines, reveals and state changes should explain architecture, flow or hierarchy — not create visual noise.

Make the interface

01 / REVEAL

Progressive disclosure

Reveal the next layer as the buyer scrolls. Never animate everything at once.

02 / SYSTEM

Orbital movement

03 / STATE

Quiet confirmation

Hover, focus, loading and form states should feel precise, immediate and accessible.

05 / The non-negotiables

Premium does not mean
more.

One dominant idea.

Every page opens with one business tension, one point of view and one primary action.

Evidence over adjectives.

Replace “best-in-class” with architecture, numbers, artifacts, process and proof wherever the evidence exists.

Glass is structural.

Use glass for controls, system maps, proof modules and layered interfaces — never as a default card treatment everywhere.

Category colour stays subordinate.

Capability pages can have distinct art direction, but Growibes blue, typography, spacing and interaction behavior remain recognizable.

Every page earns the CTA.

The final action should follow a clear escalation: understand → trust → test → talk.

Human origin remains rare.

The Himalayan story is a signature, not wallpaper. Use it where it adds meaning, then return to enterprise proof.
