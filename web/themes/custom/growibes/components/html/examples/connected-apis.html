04 / Enterprise boundaries

Composable does not mean uncontrolled.

Clear ownership

Every important data domain has a system of record and an explicit contract for how other systems consume it.

Controlled change

Version APIs and integration contracts so one system can evolve without silently breaking five others.

Visible failure

Queues, retries, dead-letter handling and observability make integration failures recoverable instead of mysterious.

05 / Drupal as the experience core

Keep Drupal where it creates leverage.

Drupal is explicitly API-first: its core JSON:API exposes content entities over HTTP, while the wider ecosystem supports GraphQL, OpenAPI, decoupled frontends and authentication patterns. That makes Drupal a strong experience and content layer inside a broader enterprise architecture — without requiring it to become the ERP, CRM or PIM.
