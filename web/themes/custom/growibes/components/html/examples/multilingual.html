Localization is not
copying a page into another language.

A global platform has to coordinate content, configuration, editorial ownership, translation, URLs, metadata, permissions and publishing across markets.

Drupal core provides language, interface translation, content translation and configuration translation capabilities — making multilingual architecture a platform concern rather than an afterthought.

01 / The global problem

Every new market can either add reach — or add chaos.

CONTENT DRIFT

Same brand. Different truth.

When markets fork content and components, consistency becomes a manual policing exercise.

EDITORIAL FRICTION

Translation becomes a bottleneck.

Publishing slows when language ownership, review states and source content are unclear.

PLATFORM SPRAWL

One country becomes one stack.

Every local exception creates another deployment, integration and maintenance surface.
